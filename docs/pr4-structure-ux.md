# PR #4 — Structure selection and configuration UX

This is a **draft**, stacked on PR #3; do not merge or claim all controls
are active until PR #3's world profile and early-load pack selection are stable.

## Priority 1: structure-set controls

- Build a catalog from **selected** Beet datapacks' real
  \`data/<namespace>/worldgen/structure_set/*.json\` resources.
- For each set, allow **enabled** and **relative weight** for each entry,
  and **Sparse / Normal / Frequent** density levels when placement is
  \`minecraft:random_spread\`.
- Preserve \`salt\`, \`spread_type\`, \`frequency\`, biome constraints, and
  unmodified structure-set entries.
- Reject empty sets and changes to progression-critical stronghold placements.
- Treat \`concentric_rings\` separately; no fake spacing slider.
- Assemble a higher-priority **per-world override pack** before registry loading;
  never apply during runtime. Only new chunks are affected.
- Source structure sets defined by vanilla / other mods require explicit
  discovery from loaded registries: this tool cannot infer them by inspecting
  SkyVoid ZIPs alone.

The prototype \`tools/structure_overrides.py\` compiles an independently
installable override datapack from selected pack directories and a JSON
configuration. It is **not wired into Minecraft's per-world pack discovery**
yet, and must not be presented in the mod UI as active functionality.

Example controls:

\`\`\`json
{
  "structure_sets": {
    "skyvoid_biome_islands:biome_islands": {
      "density": "rare",
      "structures": {
        "skyvoid_biome_islands:badlands": {"enabled": false},
        "skyvoid_biome_islands:desert": {"weight": 4}
      }
    }
  }
}
\`\`\`

## Priority 2: UX

- Fix missing section translations shown in provided screenshots.
- Replace raw worldgen/island identifiers with safe cycle/select controls.
- Replace autogenerated ID-like tooltip text with gameplay descriptions from
  the existing Additions menu source; show live/restart status and dependencies.
- Group, filter, and search many toggles; ensure changes are reversible and
  don't override a dedicated server's settings.
- Initially localize English and Portuguese where translations are available.

## Release gates

- Validate generated JSON against the Minecraft 26.2 datapack registry loader.
- Test selected-world profile with multiple packs and vanilla structure sets.
- Verify density ratios and disabled structures in newly generated chunks.
- Gameplay-test clean worlds and legacy worlds; no corruption or unintended
  changes from editing new-world defaults.
